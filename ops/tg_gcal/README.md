# SOHO Calendar Assistant (Telegram → Google Календарь)

Личный ассистент владельца: раз в сутки в 21:00 МСК забирает новые сообщения
из личного чата с @ArchTimesBot, превращает русский свободный текст в события
Google Календаря и присылает подтверждение в Telegram. Перенос работавшей
системы (142 запуска, 194 события). К публикациям канала SohoArchTimes и к
сайту отношения НЕ имеет и не касается их.

## Архитектура (облачная)
Исходный план предполагал локальную машину (~/tg-gcal, venv, cron/launchd);
развёртывание выполнялось из облачной сессии Claude Code, поэтому система
живёт в облаке — в окружении этого репозитория:

- Расписание — Routine «SOHO Calendar Assistant — 21:00 МСК» (claude.ai/code →
  Routines): ежедневно 18:00 UTC = 21:00 Europe/Moscow, каждый запуск — свежая
  Claude-сессия в этом окружении. Выполнение серверное, «спящей машины» не
  бывает — навёрстывание пропусков не требуется.
- Токен бота — только env-переменная TELEGRAM_BOT_TOKEN настроек окружения
  (в репозиторий, коммиты и логи не попадает; репозиторий публичный).
- Google Календарь — коннектор Google Calendar на claude.ai, авторизован на
  аккаунт владельца (primary). Ключей на диске нет, refresh-токенов в репо нет.
- Разбор текста выполняет сама Claude-сессия запуска строго по
  ops/tg_gcal/PARSING_RULES.md — облачный эквивалент headless `claude -p`:
  чистый «текст → события», не чаще раза в сутки и только при наличии новых
  сообщений (при пустой очереди сессия молча завершается).
- Файла состояния нет: состояние живёт на стороне Telegram через
  offset-подтверждение (`tg_pipeline.py confirm` — строго в конце
  безошибочного запуска).

## Файлы
- `tg_pipeline.py` — механика Bot API: `fetch` / `send` / `confirm`.
- `PARSING_RULES.md` — правила «текст → события» и форматы подтверждений
  (не менять без прямого указания владельца).
- `ROUTINE.md` — точная копия промпта Routine; при правке — синхронизировать
  с Routine через update_trigger.

## Управление
- Выключить всё одной командой: сказать Claude в любой сессии
  «выключи календарный ассистент» — либо claude.ai/code → Routines →
  «SOHO Calendar Assistant — 21:00 МСК» → выключить.
- Ручной запуск вне расписания: «запусти календарный ассистент сейчас».
- Лог: каждый запуск — отдельная сессия в claude.ai/code с полной историей
  (что пришло из Telegram, что создано в календаре, что отправлено).
