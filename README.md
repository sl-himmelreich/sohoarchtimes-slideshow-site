# SohoArchTimes — Слайд-шоу

Полноэкранный архитектурный слайд‑шоу‑просмотрщик: чёрная «сцена», презентационная рамка 16∶9 (эквивалент 3840×2160), сохранение исходных пропорций изображений, мягкие переходы через чёрный кадр.

## Что это

Статический сайт (HTML + CSS + JavaScript, без сборки). Открывается локально или из любого статического хостинга. Изображения подгружаются по сети **напрямую** с CDN Telegram (или с исходного источника для трёх последних постов), ничего не скачивается в бандл.

- **448** слайдов из **92** постов канала [@SohoArchTimes](https://t.me/SohoArchTimes).
- Порядок воспроизведения — от самого свежего поста к самому старому; внутри поста — в том же порядке, как в канале.
- Каждый слайд показывается **60 секунд**: 5 с появления из чёрного, 50 с показа, 5 с растворения в чёрный. Прямой кроссфейд между изображениями исключён — переход всегда через чёрный.
- Бесконечный цикл.

## Как запустить локально

1. Откройте папку проекта в терминале:

   ```bash
   cd /home/user/workspace/sohoarchtimes_slideshow_site
   ```

2. Запустите любой простой локальный сервер (`file://` не подойдёт — `fetch('./slides.json')` требует HTTP):

   ```bash
   # Вариант 1 — Python
   python3 -m http.server 8000

   # Вариант 2 — Node.js
   npx --yes serve -l 8000 .
   ```

3. Откройте в браузере:

   ```
   http://localhost:8000/
   ```

4. Нажмите в любой точке экрана, чтобы перейти в полноэкранный режим. На большом дисплее лучше всего смотрится в Chromium‑браузерах в режиме киоска:

   ```bash
   chromium --kiosk http://localhost:8000/
   ```

## Управление

Управление намеренно скрыто — оно появляется только при движении мыши и затем растворяется.

| Действие                       | Клавиатура         | Мышь                        |
| ------------------------------ | ------------------ | --------------------------- |
| Следующий слайд                | `→`, `Space`, `PgDn` | кнопка `›`                  |
| Предыдущий слайд               | `←`, `PgUp`        | кнопка `‹`                  |
| Пауза / воспроизведение        | `P`, `Space`       | кнопка `⏸ / ▶`              |
| Полноэкранный режим            | `F`                | кнопка `⤢` или клик по экрану |

Подпись в левом нижнем углу:
**Название проекта · Архитектор / Бюро · Год · Локация**

В правом нижнем углу — счётчик слайдов и название канала, очень сдержанные.

## Зависимости от сети

- Шрифты подгружаются с [Fontshare](https://www.fontshare.com/) (Satoshi, General Sans). Если шрифты не загрузились, используется системный sans‑serif — внешний вид остаётся аккуратным.
- Изображения берутся напрямую: `cdn4.telesco.pe`, `images.adsttc.com` и т. п. — ничего не кэшируется в бандле.

## Особенности и оговорки

- **3 свежих поста** (`message_id` 891, 876, 871) используют URL изображений с **первичных источников** (например, `images.adsttc.com`), потому что публичная HTML‑версия Telegram‑канала на момент сбора не отдавала их CDN‑изображения стабильно. Это помечено в `slides.json` (`"src": "source"`) и отражено в `QA_NOTES.md`. Все остальные 89 постов используют CDN Telegram (`cdn4.telesco.pe`).
- Если конкретное изображение не загрузилось за 25 секунд — оно автоматически пропускается, без белого экрана. Сцена остаётся чёрной до тех пор, пока не загрузится следующее.
- Подряд более 12 неудачных загрузок — движок ждёт 10 секунд и пробует снова с того же места.
